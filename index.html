        Architecture & Documentation

        Problem Statement: Help urban families reduce winter smog exposure using personalized low-emission routines and practical indoor air hacks.

        Hybrid GenAI + Deterministic Design: When a Gemini API key is provided in memory, VayuShield calls gemini-3-flash-preview with a strict JSON schema. If no key is supplied or a network/API error occurs, it falls back deterministically to structured AQI and household rules so core functionality never breaks.

        Security & Privacy: No secrets are hardcoded in source code; API keys are never persisted to localStorage or sessionStorage; all rendered text uses safe DOM text insertion rather than raw HTML injection.

        Accessibility & Quality: Includes skip navigation, semantic landmarks, aria-live status updates, keyboard focus rings, input bounds validation, and an automated unit test runner.
